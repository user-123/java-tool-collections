# Java Tool Collections（Java 常用工具集合）

本專案為一套封裝常用 Java 工具類與函式的集合，旨在提升開發效率，統一工具使用風格，"預計"涵蓋以下功能模組：：

- 字串處理（StringUtils）
- 時間處理（DateTimeUtils）
- 集合處理（CollectionUtils）
- 檔案與I/O操作（FileIOUtils）
- 加密/編碼工具（CryptoUtils）
- 反射與泛型工具（ReflectionUtils）
- 錯誤處理與斷言（AssertUtils）

---

## 開發環境需求
- Java JDK 版本：21
- 建構工具：Gradle 8.14.3
- 模組系統：Java Platform Module System（JPMS，模組名：org.dc.javatools）
